# 元件几何实测表（Logisim 2.15 HUST 版）

> 全部由 `PinsDump` 从 Logisim 自身读出来的 `Component.getEnds()` 得到，**不是猜的**。
> 坐标系：`loc` 是元件锚点，偏移是 `引脚 − loc`，y 轴向下。
> 自己画新元件前，先跑 `python scripts/logisim.py pins x.circ` 复核，
> 换 Logisim 版本时代码可能不同。

图例：`I` 输入脚、`O` 输出脚、`B` 双向。

## 1. 门（`#Gates`, lib=1）

`size` 决定门体大小，**输入脚的 x 偏移随 gate 外形不同**：

| 门 | size=20 | size=30 | size=50 |
|---|---|---|---|
| AND Gate | 不支持 | 输入 x-30，门体 30x30 | 输入 x-50，门体 50x50 |
| OR Gate | 不支持 | 输入 x-30，门体 30x30 | 输入 x-50，门体 50x50 |
| NAND Gate | 不支持 | 输入 x-40，门体 40x30 | 输入 x-60，门体 60x50 |
| NOR Gate | 不支持 | 输入 x-40，门体 40x30 | 输入 x-60，门体 60x50 |
| XOR Gate | 不支持 | 输入 x-40，门体 40x30 | 输入 x-60，门体 60x50 |
| XNOR Gate | 不支持 | 输入 x-50，门体 50x30 | 输入 x-70，门体 70x50 |
| NOT Gate | 输入 x-20，门体 20x18 | 输入 x-30，门体 30x18 | 不支持 |
| Buffer | 输入 x-20，门体 20x18 | 输入 x-20，门体 20x18 | 输入 x-20，门体 20x18 |

### 多输入时 y 的分布（size=30）

| 门 | inputs=2 | 3 | 4 | 5 | 6 | 8 |
|---|---|---|---|---|---|---|
| AND Gate | -10, +10 | -10, +0, +10 | -20, -10, +10, +20 | -20, -10, +0, +10, +20 | -30, -20, -10, +10, +20, +30 | -40, -30, -20, -10, +10, +20, +30, +40 |
| NAND Gate | -10, +10 | -10, +0, +10 | -20, -10, +10, +20 | -20, -10, +0, +10, +20 | -30, -20, -10, +10, +20, +30 | -40, -30, -20, -10, +10, +20, +30, +40 |

**关键**：`size=30` 时 AND/OR 输入在 `x−30`，而 NAND/NOR/XOR 在 `x−40`，
XNOR 在 `x−50`。写成同一个数会短线 10～20 格，且常被文字标签挡住看不出来。
输入数 ≥3 时**没有 y=0 的那个脚**，y 是对称地分布在 0 两侧。

`out` 属性恒为 `"01"`，与输入个数无关；写 `"001"` 会报
`attribute value (001) is not valid` 并在 headless 下变成 `HeadlessException`。

## 2. 导线类（`#Wiring`, lib=3）

| 元件 | 引脚 | 外接矩形（相对 loc） | 备注 |
|---|---|---|---|
| Pin | `O+0,+0` | (-25,-28) 25x38 | 输入脚；方框向左 |
| Pin | `I+0,+0` | (+0,-28) 25x38 | 输出脚；方框向右 |
| Pin | `O+0,+0` | (-10,-18) 20x43 | 竖放 |
| Pin | `O+0,+0` | (-45,-28) 45x38 | 4 位输入：右边多一个值框 |
| Tunnel | `I+0,+0` | (-20,-9) 21x18 | 同名相连 |
| Probe | `I+0,+0` | (-20,-10) 20x20 | 显示值 |
| Power | `O+0,+0` | (-8,-15) 16x15 | 只有 +5V 语义 |
| Ground | `O+0,+0` | (-8,+0) 16x14 | 只有 0 语义 |
| Pull Resistor | `I+0,+0` | (-6,-42) 12x42 | 单脚；facing=south 体向上 |
| Pull Resistor | `I+0,+0` | (-6,+0) 12x42 | facing=north 体向下 |
| Clock | `O+0,+0` | (-20,-10) 20x20 | 输出方波 |
| Constant | `O+0,+0` | (-16,-8) 16x16 | 恒定电平 |

- `Pin` 朝东时**连接点就是 loc**，方框朝左；朝西时仍在 loc，方框朝右。
  所以左边放输入脚用 `facing=east`，右边放输出脚用 `facing=west`。
- **输入 Pin 是驱动器**：同一网络上不能再接开关/电源，否则多驱动变成 `E`。
- **输出 Pin 是接收器**：可以挂在 Power/Ground 上看 1/0，不会冲突。
- `Pull Resistor` 只有一个脚，含义是“把本节点弱拉到 0/1”，不是两端电阻。
- `Tunnel` 靠**同名**相连，跨电路不受几何限制；但旗子会盖线，别拿它当电源符号。

## 3. 交互元件（`#I/O`, lib=7）

| 元件 | 引脚 | 外接矩形（相对 loc） | 说明 |
|---|---|---|---|
| Switch | `I-20,+0 O+0,+0` | (-20,-15) 20x30 | SPST：左 IN 右 OUT，运行时状态 |
| Switch | `I+0,-20 O+0,+0` | (-15,-20) 30x20 | 竖放 |
| DipSwitch | `O+0,+10` | (-30,+0) 30x20 | 1 位拨动；脚在 loc 下方 10 |
| DipSwitch | `O+10,+0` | (+0,-30) 20x30 | 竖放；脚在 loc 右侧 10 |
| DipSwitch | `O+10,+0 O+30,+0 O+50,+0` | (+0,-30) 60x30 | 3 位；每 20 一格 |
| Button | `O+0,+0` | (-20,-10) 20x20 | 按时为 1 |
| LED | `I+0,+0` | (+0,-10) 20x20 | 单脚；另一端元件内部接地 |
| LED | `I+0,+0` | (-20,-10) 20x20 | 体在 loc 左侧 |

- `Switch` 是**通/断**型：接 +5 V 后断开就是悬空，不能直接当 0/1 源。
  要手点出 0/1 用 `DipSwitch`，或自己做 SPDT 子电路。
- `DipSwitch` 的**“关”位在离引脚最远的一端**：朝南放时 0 = 滑块在上。
- `LED` 只有一个连接点，另一端在元件内部接地；实物要串 470 Ω。

## 6. 位宽与总线（多位数）

| 元件 | 属性（`FactoryDump` 实测） | 说明 |
|---|---|---|
| `Pin` | `width` | `width=N` 时连接点仍是 `loc`，右边多出 N 个格的值框 |
| `Splitter` | `fanout` `incoming` `bit0..bitN` | `incoming`=输入总线宽度，`fanout`=分出的线数；第 i 根接 `bit{i}` 指定的位 |
| `Bit Extender` | `in_width` `out_width` `type` | `type` = zero/sign/one |
| `Adder` / `Subtractor` | `width` | 进位/借位脚在 `loc` 的左下 |
| `Comparator` | `width` `mode` | `mode` = twosComplement/unsigned |
| `Register` | `width` `trigger` `Select` | `Select` = low/high（使能极性） |
| `Counter` | `width` `max` `ongoal` `trigger` `behavior` | `ongoal` = wrap/stay/… |
| `RAM` / `ROM` | `addrWidth` `dataWidth` `bus` `Select` | `bus` = combined/separate |

要点：

1. **2.15 的 `Splitter` 不支持多位数扇出**：`bit0="1,2"` 这种写法会加载失败；
   一位一根，`fanout=4, incoming=4, bit0..bit3 = 1..4`。
2. 多位 `Pin` 的**值框**占几十格宽，相邻 Pin 纵向间距按 ≥60 留，否则框叠框。
3. `Hex Digit Display` 有**两个输入脚**（`loc` 与 `loc+10,0`），第二位不是数据位；
   4 位总线横穿过去会被当成接上。
4. 功能块（Register/Counter/RAM…）的 `getEnds()` 顺序**不等于引脚名顺序**；
   画图前用 `logisim.py pins` 看坐标，接完先 `sim` 或 `values` 验证，别按记忆连。
5. 2.15 HUST 版**没有** `decimalPoint` 这类 evolution 专有属性；
   从 Logisim-evolution 的示例抄属性会加载失败，以 `FactoryDump` 输出为准。
