# 实验一~三：实际做法与可复用资产

> 三个实验里 Logisim 的角色不同。这里记的是**能直接抄的做法**。
> 路径都写成相对形式：你的工程只要按 `Exp1/ Exp2/ Exp3/` 组织即可对上。

---

## 0. 分工结论（先记这个）

| 需求 | 用什么 |
|---|---|
| 报告里的黑白逻辑图、要打印 | **Logisim**（`.circ` + `CircExport`） |
| 真值表验证（手点开关） | **Logisim**（`sim` / `DipSwitch`） |
| 真实 74LS 电气特性、探针读数、动画开关 | Multisim `.ms14` |
| 芯片引脚图 / 面包板示意 | Multisim / circuitMint / 手绘 |
| 版本管理、diff | **Logisim**（明文 XML） |

**同一张图不要两边都维护。** 报告配图交给 Logisim，`.ms14` 只在需要真实电气特性的仿真数据时才做，
坐标互不复用。

## 1. 实验一：TTL 门电路功能测试

Logisim 没有参与出图（用的是 Multisim `.ms14`），**但提供了三样东西**：

### 1.1 芯片引脚号（Logisim 里画接线图时要标）

**74LS00**（四 2 输入与非门）：

| 门 | 输入 | 输出 |
|---|---|---|
| U1A | 1、2 | 3 |
| U1B | 4、5 | 6 |
| U1C | 9、10 | 8 |
| U1D | 12、13 | 11 |

**74LS02**（四 2 输入或非门）：`2,3→1 / 5,6→4 / 8,9→10 / 11,12→13`

**74LS20**（双 4 输入与非门）：

| 门 | 输入 | 输出 |
|---|---|---|
| U2A | 1、2、4、5 | 6 |
| U2B | 9、10、12、13 | 8 |

**74LS86**（四 2 输入异或门）：`1,2→3 / 4,5→6 / 9,10→8 / 12,13→11`

**74LS125**（四三态缓冲，低有效使能）：`1=1OE 2=1A 3=1Y / 4=2OE 5=2A 6=2Y / 8=3Y 9=3A 10=3OE / 11=4Y 12=4A 13=4OE`

**CD4071**（四 2 输入或门，CMOS）：`1,2→3 / 5,6→4 / 8,9→10 / 12,13→11`

所有 14 脚封装：**14 → VCC，7 → GND**；74LS20 的 3、11 为空脚。

### 1.2 实验一的“实验台”画法 → 实验三直接复用

| 实验一 `.ms14` | Logisim 里对应 |
|---|---|
| VCC 5.0V + 10k 上拉 | `Power` + `Pull Resistor` |
| 动画开关 S1/S2（键=1/2） | `SPDT_SEL` + `DipSwitch` 扳手 |
| U1A 74LS00D 门符号 | `NAND Gate` + 上方位号/逻辑式 |
| 输出探针 X1（2.5 V） | `LED` 或 `Probe` |
| 隐藏的 14/7 电源脚 | 图下方文字说明 |

### 1.3 多余端处理的结论（画图时要体现）

- 输入多余端接 +5 V 或与在用输入并接 —— 都可以；
- **悬空是不允许的**（TTL 悬空等于高电平，但抗干扰差、易误判）；
- 实验一里“设计 H/I”故意悬空是为了演示这个坑，接线图里要标出来。

## 2. 实验二：组合逻辑设计（1）

产出：半加器 / 全加器 / 得奖电路，**三张逻辑图 + 三张接线图**。

### 2.1 电路

| 电路 | 逻辑 | 门 |
|---|---|---|
| 半加器 | `S=A⊕B`，`C=AB` | 5 个 NAND2 |
| 全加器 | `Si=Ai⊕Bi⊕Ci`，`Co=AiBi+(Ai⊕Bi)Ci` | 2 XOR + 3 NAND2 |
| 得奖 | `Z=AB+AC=A(B+C)` | 3 NAND2 |

### 2.2 可复用资产

```
Exp2\Logisim\
  实验二_全部电路.circ     ← 三个接线图（开关/LED）在同一工程
  半加器.circ / 全加器.circ / 得奖电路.circ
  _逻辑图\                 ← 纯逻辑图（报告配图用）
  _备份\                   ← 用户改动、版面整理前的版本
  SPDT封装demo.circ        ← SPDT / SPDT_SEL / SPDT_SW 子电路
Exp2\scripts\build_logisim.py   ← 生成 + 自检 + 真值表 + 渲染（最完整的例子）
```

`build_logisim.py` 是**本 skill 的祖本**：`Circuit` 类、工具栏生成、几何自检、
真值表求解、`--render` 全在里面。它的能力现在都已拆进 `scripts/` 与 `java/`，
`templates/make_circ.py` 保留了最小骨架，可以直接改。

### 2.3 踩过的点

- 原来的文档写“AND 类输入在 `x−30`、XOR 才 `−40`”，实测**不准确**：
  `size=30` 时 AND/OR `−30`、NAND/NOR/XOR `−40`、XNOR `−50`。
  （见 `references/02_geometry.md`）
- 门的 `label` 会画在门体里 → 位号用 `Text`。
- 布局用**真实导线 + 竖直干线**，不要在门输入上堆 `Tunnel` 旗子。
- 报告配图和照画图要分目录导出（`图片\` vs `图片\Multisim对照\`），否则 `--render` 会覆盖。

## 3. 实验三：三人表决器

### 3.1 两种方案（都要画）

| | 纯 74LS00 | 74LS00 + 74LS20 |
|---|---|---|
| 门数 | 6 个 NAND2 | 3 个 NAND2 + 1 个 NAND4 |
| 芯片 | 74LS00 ×2 | 74LS00 ×1、74LS20 ×1 |
| 级数 | 3 级 | 2 级 |
| 说明 | 只用一种芯片，接线多 | 门数最省；74LS20 第 4 脚接 +5 V |

```
方案一：n1=(AB)′  n2=(AC)′  n3=(BC)′  n4=(n1n2)′  n5=(n4n4)′=n1n2  L=(n5n3)′
方案二：n1=(AB)′  n2=(AC)′  n3=(BC)′  L=(n1n2n3·1)′
```

得奖电路（拓展）：`Z=AB+AC=A(B+C)`，3 个 NAND2，74LS00 一片。

### 3.2 SPDT_SEL 是本实验的关键

见 `SKILL.md §7` 和 `templates/spdt_sel.circ`。核心三点：

1. **两个掷是输入、刀是输出**（真实开关的接法）；
2. 内部用 **2 选 1 多路选择器**，不是两个传输门并联；
3. 扳手放方块上方朝南，`S=0`（朝上）= 接 T1 = +5 V = 1。

### 3.3 结果（已用 Logisim 仿真验证）

三人表决器 8/8：`000→1 100→1 010→1 110→0 001→1 101→0 011→0 111→0`
（**这里 0 = 扳手朝上 = 逻辑 1**，所以 `000` 对应 A=B=C=1）

得奖电路 8/8：`000→1`，其余只有 `010/001`（A=1 且 B 或 C 为 1）→1。

### 3.4 资产

```
Exp3\Logisim\实验三_全部电路.circ   ← 3 个接线图 + SPDT_SEL 子电路
Exp3\Logisim\实验三_逻辑图.circ     ← 3 个纯逻辑图
Exp3\scripts\build_exp3_logisim.py  ← 生成脚本（含 SPDT_SEL 的 <appear> 源码）
```

`build_exp3_logisim.py` 里的 `SPDT_SEL_XML` 常量是**子电路外观的完整样例**：
`<appear>` + `<circ-port>` + `<circ-anchor>` + 内部 `<Multiplexer>`，可直接改。
（本仓库 `templates/spdt_sel.circ` 就是它导出的成品。）

## 4. 三个实验共同的结论

1. **打印用图交给 Logisim**，`.ms14` 只做需要真实电气特性的仿真。
2. **`.circ` 是明文** → 可以脚本生成、可以 diff、可以审计；`.ms14` 不行。
3. **几何即连接**：坐标对了就真的连上，坐标错了不报错——所以必须脚本审计。
4. **用 Logisim 自己的引擎出图和仿真**，不要另写渲染器/求值器。
5. **用户手改过的文件先备份**，再谈覆盖。

## 5. 和 Multisim 的衔接

简单说：**同一张图不要两边都维护**。
要从 Logisim 图照画到 Multisim 时，接线图（带开关/LED/引脚号）比逻辑图好用，
导出到单独目录（如 `图片\Multisim对照\`）避免覆盖报告图。

## 6. 三个实验里怎么用新加的两个命令

### 6.1 `values`：报告“线变红了”时先跑这个

GUI 里红线 = `E`（多驱动/冲突），但**戳一下导线也会红，而且不写盘**。

```bash
python scripts/logisim.py values "…\实验三_全部电路.circ" "拓展_得奖电路" --red
# 合计：绿(1)=18 深绿(0)=12 蓝(x)=0 红(E)=0   ← 文件是干净的
```

2026-11 实际遇到过一次：`拓展_得奖电路` 的三根输出线在 GUI 里发红，磁盘文件 8 种开关组合全是 `红(E)=0`，
结论是 Poke 工具戳出来的运行时状态，`Ctrl+R` 复位即恢复。
所以**先 `values`，再动文件**，不要凭肉眼删线。

### 6.2 `check`：证明“只用了一片 74LS00”

实验要求常写“限用 74LS00”“不得用现成加法器”。这是**题面约束**，`audit` 不管，
用 `check`：

```bash
python scripts/logisim.py check 实验三_逻辑图.circ 逻辑图_表决器_74LS00 `
    --require "A 输入:1:in" --require "B 输入:1:in" --require "C 输入:1:in" `
    --require "L 输出:1:out" --forbid-lib "#Arithmetic" --forbid "Adder,Subtractor"
```

- `--forbid-lib "#Gates"` 可以证明“门全部来自 TTL 芯片库”。
- `--max-comps 40` 防“偷偷塞了一堆门”；
- `--no-halt` 防交付件里留下验证用的 halt。

`PASS/FAIL` 一行一项，有失败时返回码 1，可以直接挂在批改脚本里。

### 6.3 以后做计数器/寄存器：`sim --clock`

实验四起会有触发器和计数器。组合真值表扫不出来，用逐拍模式：

```bash
python scripts/logisim.py sim 计数器.circ 四位计数器 500,300 --clock CLK --ticks 8
# t0 -> 0000
# t1 -> 0001
# ...
```

要点：

- 时钟必须画成**输入 `Pin`**（或 1 位 `DipSwitch`）并起标签 `CLK`，
  不要用 `Clock` 元件——`Clock` 由仿真线程自己振，工具不接管。
- `--ticks N` 打 N 个上升沿，采样在上升沿之后，正好对应 `trigger=rising`。
- 有别的输入（置数、使能）时用 `--combo` 固定它们。
- 模板 `templates/make_circ.py` 只到组合逻辑；时序就先手写 XML，
  再用 `pins` 量 Counter/Register 的脚（`references/02_geometry.md §4`）。
